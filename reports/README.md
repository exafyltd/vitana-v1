# Vitana Card Inventory Reports

This directory contains generated reports about the Vitana card system.

## Files

- `cards_by_screen.md` - Complete inventory of cards used across all screens, generated by the inventory script
- Generated automatically using `npm run generate-inventory`

## Usage

To regenerate the inventory report:

```bash
cd scripts
npm run generate-inventory
```

This will scan all 72+ screens in the Vitana app and produce a comprehensive mapping of:
- Card Templates (CT-XXX) used per screen/slot
- System Cards (C-XXX) placement and purpose
- Screen-specific card configurations

## Card ID System

### Template IDs (CT-XXX)
- **CT-CX-001** through **CT-CX-010**: CrossoverCard family
- **CT-HS-001** through **CT-HS-004**: Health components
- **CT-MD-001** through **CT-MD-003**: Media cards
- **CT-UT-001** through **CT-UT-002**: Utility components

### System Card IDs (C-XXX)  
- **C-001**: Main Vitana Index Display
- **C-002**: Autopilot Status & Controls
- **C-003**: Health Coach Chat Interface
- **C-004**: Smart Suggestions Engine
- **C-005**: Quick Health Logging
- **C-006**: Community Activity Pulse
- **C-007**: Progress Streaks Tracker
- **C-008**: Smart Calendar Integration
- **C-009**: Health Data Wallet
- **C-010**: Lifestyle Plan Manager

All cards are now tracked with `data-template-id` and `data-system-card-id` attributes for analytics and A/B testing.
