# Journey illustrations

Drop the curated AI-painted illustrations here. The components reference
these paths directly; if a file is missing, the soft pastel-sunrise
CSS gradient behind it shows through so the screen never breaks.

## Required assets

| Path | Used by | Aspect | Notes |
|---|---|---|---|
| `journey-coast.webp` | `DreamNorthStar` | 3 : 4 portrait | The painted hero background. Pastel sunrise / Mediterranean coast / soft balloons. Match the dream-board reference: warm sunrise, dreamy, painted (not photographic), not cartoonish. |
| `future-self-stronger.webp` | `FutureSelfTiles` | 1 : 1.1 portrait | "Stärker · 5 km laufen" tile. Painted scene of movement / dawn run / hill path / strong morning light. |
| `future-self-calmer.webp` | `FutureSelfTiles` | 1 : 1.1 portrait | "Ruhiger · besser schlafen" tile. Painted scene of stillness / moonlit window / cool dusk / soft bed. |

## Style direction

- Painted illustration (gouache / watercolor / soft brushstrokes) — **not** photography.
- Pastel palette: blush pink, lavender, peach, soft blue, warm yellow.
- Warm sunrise/golden-hour lighting.
- Calm, elegant, dreamy — premium magazine quality.
- No people's faces close-up (read as silhouettes / distant figures so any user feels reflected).
- File format: `webp` preferred (smaller); `png` or `jpg` also work — just change the import path.
- Target resolution: ~1200×1600 for the hero, ~600×660 for tiles. Compress to <200 KB each.

## Production sourcing

V1: curated AI-generated set (Midjourney / Sora / etc), human-picked.
V2: commission 3-5 painted variants per pillar (vitality coast, mind
mountain, nutrition garden, social city, finance forest) so the hero
reflects the user's life-compass focus.
